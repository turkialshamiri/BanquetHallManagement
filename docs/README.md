## ملخص سريع — الإصدار 2.0

### دورة الحجز

```text
Pending → (عربون ≥30%) → Confirmed → (أقساط ≥20%) → FullyPaid → (تأكيد دخول) → Completed
```

### قواعد أساسية

| القاعدة | التفاصيل |
|---------|----------|
| حجوزات معلقة متعارضة | مسموحة حتى دفع العربون |
| أول عربون | يؤكد الحجز ويلغي المتعارضة |
| العربون | إيراد فوري — **غير مسترد** |
| الأقساط | إيراد مؤجّل — **قابلة للاسترداد** |
| عدم السداد قبل ساعتين | إلغاء auto — العربون يبقى |
| تأكيد دخول القاعة | ترحيل المؤجّل إلى إيراد نهائي |

للتفاصيل الكاملة راجع [financial-system-design.md](./financial-system-design.md).
